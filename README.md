# Fifty Coffees — PA3 (demostración docente)

Implementación independiente basada en las capturas y rúbrica del documento PA3. **No incluye ni modifica el repositorio PA2 del docente**.

## Uso
Abre `index.html` en un navegador. Recorre el menú para ver las seis páginas. La tabla, el formulario y el mapa están en `contactos.html`; las áreas CSS Grid, las columnas y las fuentes externas en `nosotros.html`.

## Notas
- Formulario: solo validación del navegador y confirmación local; no se guardan ni envían mensajes.
- Dirección: referencia tomada del ejemplo de la evaluación; correo, teléfono y horario son ficticios.
- Mapa y fuentes Google requieren conexión a internet.
- Blog, Galería y Videos son secciones demostrativas, para sustituir por el contenido real de PA2.
- Para publicar: activar Settings → Pages → Deploy from a branch → main / root.
